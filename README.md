# Kids Kingdom CIC Website

This repository contains the website files for Kids Kingdom CIC.

## Project Overview

The site presents Kids Kingdom CIC's mission, programmes, contact information, and supporting content for families, schools, and community partners.

## Files

- `index.html` - homepage
- `about.html` - about page
- `programmes.html` - programmes page
- `contact.html` - contact page
- `events.html` - additional site page
- `style.css` - shared styling
- `script.js` - shared interactivity
